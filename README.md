# Poly West

Ein Low-Poly-Western im Browser. Die erste Stadt heißt Dust Creek. Das ganze Spiel ist eine einzige HTML-Datei: `dist/poly-west.html`.

- **PC:** WASD gehen, Shift rennen, Maus Kamera, Linksklick schlagen, Q Revolver, Rechtsklick zielen, R laden, E benutzen.
- **Handy (quer):** links ziehen = laufen, rechts ziehen = Kamera, Knöpfe rechts.

Für die Entwicklung siehe `CLAUDE.md`: Aufbau, Befehle, Tests und Konventionen.
